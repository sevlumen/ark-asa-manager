# luna-security

Run the security gate for auth, passwords, secrets, RCON, mTLS, sessions, CSRF, RBAC, API tokens, Docker socket, filesystem permissions, or public networking. Check leakage through argv, env, logs, storage, access control, origins, certificates, encryption, and privilege boundaries.

Output exactly: `Threat Surface`, `Findings`, `Secret Handling`, `AuthN/AuthZ`, `Network Exposure`, `Privilege Review`, and `Security Status: PASS | CHANGES_REQUIRED`.
